# README for "tidyfinance: Transparent Factor Construction for Empirical Asset Pricing" (Frey, Scheuch, Voigt, and Weiss)

## Overview

This replication package renders the Quarto manuscript submitted to the *Journal of Statistical Software*. The manuscript demonstrates the [tidyfinance](https://github.com/tidy-finance/r-tidyfinance) R package by reproducing the asset-growth factor end-to-end from raw CRSP and Compustat data and by summarising a precomputed factor library hosted on Hugging Face. Two rendering paths are supported:

1. **Default path.** Pulls the precomputed factor library from Hugging Face at render time and downloads CRSP/Compustat extracts via the WRDS API. Expected runtime: about 15 minutes on a laptop.
2. **Synthetic-data path.** Renders without a WRDS subscription using schema-compatible synthetic data generated by `tidyfinance`. The workflow reproduces; numerical results are simulated.

### Details on each Data Source

#### CRSP Monthly Stock File (proprietary)

The Center for Research in Security Prices (CRSP) Monthly Stock File provides US equity returns, prices, shares outstanding, and delisting information. The paper uses 1972 through 2024. Access requires an institutional WRDS subscription (`https://wrds-www.wharton.upenn.edu/`). Data are downloaded via the `tidyfinance::download_data("wrds_crsp_monthly")` interface, which wraps the WRDS PostgreSQL API. Configure WRDS credentials once with `tidyfinance::set_wrds_credentials()`. The raw extracts are not redistributed.

#### Compustat Fundamentals Annual (proprietary)

S&P Global Compustat Fundamentals Annual provides accounting data including total assets used to construct the asset-growth signal. Access requires WRDS, as above. Data are downloaded via `tidyfinance::download_data("wrds_compustat_annual")`. The raw extracts are not redistributed.

#### Ken French Data Library (public)

Monthly Fama-French three-factor returns are downloaded via `tidyfinance::download_data("factors_ff_3_monthly")` from `https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html`. The data are freely available subject to the citation requirement on the source page.

#### `tidyfinance` factor library (public, authors' artefact)

A precomputed library of long-short portfolio returns across `r format(nrow(tidyfinance::download_data("tidyfinance", "factor_library_grid")), big.mark = ",")` construction specifications is hosted on Hugging Face under `tidy-finance/factor_library`. Replicators access the library via `tidyfinance::download_data("tidyfinance", "factor_library", sorting_variable = "ag")`. License: CC-BY-4.0.

## Instructions to Replicators

### Path 1: Render the manuscript (default, recommended)

1. Clone the repository and open the project root in R or in your shell.
2. Install `renv` and restore the locked environment:

   ```r
   install.packages("renv")
   renv::restore()
   ```

3. Configure WRDS credentials once (skip if you will use the synthetic-data path):

   ```r
   library(tidyfinance)
   set_wrds_credentials()
   ```

4. Render the PDF from the project root:

   ```bash
   quarto render jss-manuscript.qmd
   ```

### Path 2: Render without WRDS (synthetic data)

Open `jss-manuscript.qmd`, find the `set-data-domain` chunk at the top of Section 4, and change

```r
data_domain <- "wrds"
```

to

```r
data_domain <- "pseudo"
```

Every chunk that would otherwise download CRSP or Compustat then dispatches to the `domain = "pseudo"` path in `tidyfinance`, which generates schema-compatible synthetic data. The workflow reproduces; numerical results are simulated. The `seed` and `n_assets` arguments to `download_data()` control the synthetic draws.
