# README for "tidyfinance: Transparent Factor Construction for Empirical Asset Pricing" (Frey, Scheuch, Voigt, and Weiss)

## Overview

This replication package renders the Quarto manuscript submitted to the *Journal of Statistical Software*. The manuscript demonstrates the [tidyfinance](https://github.com/tidy-finance/r-tidyfinance) R package by reproducing the asset-growth factor end-to-end from raw CRSP and Compustat data and by summarising a precomputed Tidy Finance Factor Library hosted on Hugging Face.

The entire package is built by running a single command — `quarto render jss-manuscript.qmd` — from the project root. Two rendering paths are supported:

1. **Default path.** Pulls the precomputed factor library from Hugging Face at render time and downloads CRSP/Compustat extracts via WRDS. Requires an institutional WRDS subscription and an active internet connection. Expected runtime: about 15 minutes on a standard laptop.
2. **Pseudo-data path.** Renders without a WRDS subscription using schema-compatible pseudo data generated by `tidyfinance`. The workflow reproduces in full; numerical results are simulated rather than the paper's actual estimates. Expected runtime: about 5 minutes standard laptop.

All data are downloaded or generated at render time; no data files are committed to the repository.

### Details on each Data Source

#### CRSP Monthly Stock File (proprietary)

The Center for Research in Security Prices (CRSP) Monthly Stock File provides US equity returns, prices, shares outstanding, and delisting information. The paper uses 1972 through 2024. Access requires an institutional WRDS subscription. Data are downloaded via the `tidyfinance::download_data("wrds_crsp_monthly")` interface, which wraps the WRDS PostgreSQL API and returns an R data frame. Configure WRDS credentials once with `tidyfinance::set_wrds_credentials()`. The raw extracts are not redistributed.

- Format: R data frame returned by the WRDS PostgreSQL pull
- Access: Subscription-based; requires institutional WRDS license
- Download method: Automatic, via `tidyfinance::download_data()` at render time
- Provided: No (proprietary; redistribution not permitted)

#### Compustat Fundamentals Annual (proprietary)

S&P Global Compustat Fundamentals Annual provides accounting data including total assets, used to construct the asset-growth signal. Access requires WRDS, as above. Data are downloaded via `tidyfinance::download_data("wrds_compustat_annual")`. The raw extracts are not redistributed.

- Format: R data frame returned by the WRDS PostgreSQL pull
- Access: Subscription-based; requires institutional WRDS license
- Download method: Automatic, via `tidyfinance::download_data()` at render time
- Provided: No (proprietary; redistribution not permitted)

#### Ken French Data Library (public)

Monthly Fama-French three-factor returns are downloaded via `tidyfinance::download_data("factors_ff_3_monthly")` from `https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html`. The data are freely available subject to the citation requirement on the source page.

- Format: R data frame (CSV source on the website)
- Access: Public, no registration required
- Download method: Automatic, via `tidyfinance::download_data()` at render time
- Provided: No (freely re-downloadable from the source)

#### Tidy Finance Factor Library (public, authors' artefact)

A precomputed library of long-short portfolio returns across 841,536 construction specifications is hosted on Hugging Face under `tidy-finance/factor-library`. Replicators access the library via `tidyfinance::download_data("tidyfinance", "factor_library", sorting_variable = "ag")`.

- Format: R data frame (Parquet on Hugging Face)
- Access: Public; CC-BY-4.0
- Download method: Automatic, via `tidyfinance::download_data()` at render time, pinned to revision [FILL IN: Hugging Face dataset revision hash]
- Provided: No (downloaded at render time; see reproducibility note)
- License: CC-BY-4.0

## Computational Requirements

### Software Requirements

- R 4.5.2 (versions of every package are pinned in `renv.lock`)
- `renv` package, used to restore the locked package environment
- Quarto (tested with version 1.5 or later) and a working TeX distribution (e.g., TinyTeX or TeX Live) for PDF rendering
- `tidyfinance` version 0.6.0, as recorded in `renv.lock`
- An institutional WRDS account, unless rendering with `data_domain <- "pseudo"`

The file `renv.lock` lists every package and the exact version used. Running `renv::restore()` once from the project root installs the full set of **R packages**. Quarto and a TeX distribution are not R packages and must be installed separately (see "Instructions to Replicators").

All file paths in the package are relative to the project root, so no manual path editing is required.

### Controlled Randomness

Random seeds are set at the chunk level inside `jss-manuscript.qmd` and via the `seed` argument to `tidyfinance::download_data()` when generating pseudo data. No global seed is required for the production (WRDS) path because all randomness lives in the pseudo-data simulator.

### Memory, Runtime, Storage Requirements

#### Summary time to reproduce

10-60 minutes (default WRDS path: about 15 minutes on a 2024-era laptop; pseudo path: about 5 minutes)

#### Summary of required storage space

2 GB - 25 GB (CRSP and Compustat extracts plus the precomputed factor library, downloaded at render time)

#### Computational Details

The manuscript was last compiled on an **Apple MacBook Pro (M3 Pro, 18 GB RAM, macOS 14)** with **about 15 minutes** of wall time. The package runs without modification on Windows, macOS, and Linux.

## Instructions to Replicators

### Prerequisites (clean machine)

1. Install **R 4.5.2 or later**.
2. Install **Quarto 1.5 or later** (`https://quarto.org`).
3. Install a **TeX distribution** for PDF output, e.g. run `quarto install tinytex` or, from R, `tinytex::install_tinytex()`.
4. Ensure an **active internet connection** (all data are downloaded at render time).
5. For the default path only: an **institutional WRDS account**.

### Path 1: Render the manuscript (default, recommended)

1. Clone the repository and open the project root in R or in your shell.
2. Install `renv` and restore the locked environment:

   ```r
   install.packages("renv")
   renv::restore()
   ```

3. Configure WRDS credentials once (skip if you will use the pseudo-data path):

   ```r
   library(tidyfinance)
   set_wrds_credentials()
   ```

4. Render the PDF from the project root:

   ```bash
   quarto render jss-manuscript.qmd
   ```

### Path 2: Render without WRDS (pseudo data)

Open `jss-manuscript.qmd`, find the `set-data-domain` chunk at the top of Section 4, and change

```r
data_domain <- "wrds"
```

to

```r
data_domain <- "pseudo"
```

Every chunk that would otherwise download CRSP or Compustat then dispatches to the `domain = "pseudo"` path in `tidyfinance`, which generates schema-compatible pseudo data. The workflow reproduces in full; numerical results are simulated. The `seed` and `n_assets` arguments to `download_data()` control the random draws.

## Notes on Reproducibility (data vintage)

Because the raw CRSP/Compustat extracts and the Tidy Finance Factor Library are downloaded **at render time** rather than from a frozen snapshot, exact numerical reproduction depends on the data vintage. The results in the paper were produced using data accessed on June 1, 2026. CRSP and Compustat periodically revise historical data, so re-downloaded extracts may differ slightly from the paper's vintage.
