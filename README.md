# README for "tidyfinance: Transparent Factor Construction for Empirical Asset Pricing" (Frey, Scheuch, Voigt, and Weiss)

## Overview

This replication package renders the R Markdown manuscript prepared for *The R Journal*. The manuscript demonstrates the [tidyfinance](https://github.com/tidy-finance/r-tidyfinance) R package by reproducing the asset-growth factor of Cooper, Gulen, and Schill (2008) end-to-end from raw CRSP and Compustat data.

The manuscript is produced by rendering a single file — `tidyfinance.Rmd` — from the project root with `rmarkdown::render("tidyfinance.Rmd")`. Two rendering paths are supported:

1. **Default path.** Downloads CRSP/Compustat extracts via WRDS and the Fama-French factors from Ken French's Data Library at render time. Requires an institutional WRDS subscription and an active internet connection. Expected runtime: about 15 minutes on a standard laptop.
2. **Pseudo-data path.** Renders without a WRDS subscription using schema-compatible pseudo data generated by `tidyfinance`. The workflow reproduces in full; numerical results are simulated rather than the paper's actual estimates. Expected runtime: less than 5 minutes on a standard laptop.

All data are downloaded or generated at render time; no data files are committed to the repository.

### Details on each Data Source

#### CRSP Monthly Stock File (proprietary)

The Center for Research in Security Prices (CRSP) Monthly Stock File provides US equity returns, prices, shares outstanding, and delisting information. The paper uses 1972 through 2024. Access requires an institutional WRDS subscription. Data are downloaded via `tidyfinance::download_data(domain = "wrds", dataset = "crsp_monthly")`, which wraps the WRDS PostgreSQL API and returns an R data frame. Configure WRDS credentials once with `tidyfinance::set_wrds_credentials()`. The raw extracts are not redistributed.

- Format: R data frame returned by the WRDS PostgreSQL pull
- Access: Subscription-based; requires institutional WRDS license
- Download method: Automatic, via `tidyfinance::download_data()` at render time
- Provided: No (proprietary; redistribution not permitted)

#### Compustat Fundamentals Annual (proprietary)

S&P Global Compustat Fundamentals Annual provides accounting data including total assets, used to construct the asset-growth signal. Access requires WRDS, as above. Data are downloaded via `tidyfinance::download_data(domain = "wrds", dataset = "compustat_annual")`. The raw extracts are not redistributed.

- Format: R data frame returned by the WRDS PostgreSQL pull
- Access: Subscription-based; requires institutional WRDS license
- Download method: Automatic, via `tidyfinance::download_data()` at render time
- Provided: No (proprietary; redistribution not permitted)

#### Ken French Data Library (public)

Monthly Fama-French three-factor returns are downloaded via `tidyfinance::download_data(domain = "factors_ff", dataset = "Fama/French 3 Factors")` from `https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html`. The data are freely available subject to the citation requirement on the source page.

- Format: R data frame (CSV source on the website)
- Access: Public, no registration required
- Download method: Automatic, via `tidyfinance::download_data()` at render time
- Provided: No (freely re-downloadable from the source)

## Computational Requirements

### Software Requirements

- R 4.5.2 (versions of every package are pinned in `renv.lock`)
- `renv` package, used to restore the locked package environment
- `rmarkdown` and `rjtools` to render the article, together with `pandoc` (bundled with RStudio, or installed separately) and a working TeX distribution (e.g., TinyTeX or TeX Live) for PDF output
- `tidyfinance` version 0.6.0.9003, as recorded in `renv.lock`
- An institutional WRDS account, unless rendering with `data_domain <- "pseudo"`

The file `renv.lock` lists every package and the exact version used. Running `renv::restore()` once from the project root installs the full set of **R packages**. Pandoc and a TeX distribution are not R packages and must be installed separately (see "Instructions to Replicators").

All file paths in the package are relative to the project root, so no manual path editing is required.

### Controlled Randomness

Random seeds are set at the chunk level inside `tidyfinance.Rmd` and via the `seed` argument to `tidyfinance::download_data()` when generating pseudo data. No global seed is required for the production (WRDS) path because all randomness lives in the pseudo-data simulator.

### Memory, Runtime, Storage Requirements

#### Summary time to reproduce

5-30 minutes (default WRDS path: about 15 minutes on a 2024-era laptop; pseudo path: less than 5 minutes).

#### Summary of required storage space

About 1-2 GB (CRSP and Compustat extracts, downloaded at render time).

#### Computational Details

The manuscript was last compiled on an **Apple MacBook Air (M1, 16 GB RAM, 8 cores)** in **about 15 minutes**. The package runs without modification on Windows, macOS, and Linux.

## Instructions to Replicators

### Prerequisites (clean machine)

1. Install **R 4.5.2 or later**.
2. Install **pandoc** (bundled with RStudio, or available from `https://pandoc.org`).
3. Install a **TeX distribution** for PDF output, e.g. from R run `tinytex::install_tinytex()`.
4. Ensure an **active internet connection** (all data are downloaded at render time).
5. For the default path only: an **institutional WRDS account**.

### Path 1: Render the manuscript (default, recommended)

1. Clone the repository and open the project root in R or in your shell.
2. Install `renv` and restore the locked environment:

   ```r
   install.packages("renv")
   renv::restore()
   ```

3. Configure WRDS credentials once (skip if you will use the pseudo-data path):

   ```r
   library(tidyfinance)
   set_wrds_credentials()
   ```

4. Render the PDF from the project root:

   ```r
   rmarkdown::render("tidyfinance.Rmd")
   ```

### Path 2: Render without WRDS (pseudo data)

Open `tidyfinance.Rmd`, find the `set-data-domain` chunk near the top of the case study, and change

```r
data_domain <- "wrds"
```

to

```r
data_domain <- "pseudo"
```

Every chunk that would otherwise download CRSP or Compustat then dispatches to the `domain = "pseudo"` path in `tidyfinance`, which generates schema-compatible pseudo data. The workflow reproduces in full; numerical results are simulated. The `seed` and `n_assets` arguments to `download_data()` control the random draws.

## Notes on Reproducibility (data vintage)

Because the raw CRSP/Compustat extracts are downloaded **at render time** rather than from a frozen snapshot, exact numerical reproduction depends on the data vintage. CRSP and Compustat periodically revise historical data, so re-downloaded extracts may differ slightly from the paper's vintage.
