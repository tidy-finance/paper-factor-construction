# README for "tidyfinance: Transparent Factor Construction for Empirical Asset Pricing" (Frey, Scheuch, Voigt, and Weiss)

## Overview

The code in this replication package builds the Quarto manuscript submitted to the *Journal of Statistical Software* and reproduces every table and figure in the paper. The manuscript demonstrates the [tidyfinance](https://github.com/tidy-finance/r-tidyfinance) R package by reproducing the asset-growth factor end-to-end from raw CRSP and Compustat data and by summarising a precomputed factor library hosted on Hugging Face. Two paths are supported:

1. **Render the manuscript** (default). Pulls the precomputed factor library from Hugging Face at render time and downloads CRSP/Compustat extracts via the WRDS API. Expected runtime: about 15 minutes on a laptop.
2. **Audit path** (optional). Rebuilds the precomputed factor library from raw WRDS data using the scripts in `code/`. Expected runtime: about 3 hours on a 64-core server.

Replicators without a WRDS subscription can render the manuscript against synthetic data of identical schema generated by `tidyfinance` (see [Instructions to Replicators](#instructions-to-replicators)). The synthetic path reproduces the workflow; numerical results are simulated.

### Details on each Data Source

#### CRSP Monthly Stock File (proprietary)

The Center for Research in Security Prices (CRSP) Monthly Stock File provides US equity returns, prices, shares outstanding, and delisting information. The paper uses 1972 through 2024. Access requires an institutional WRDS subscription (`https://wrds-www.wharton.upenn.edu/`). Data are downloaded via the `tidyfinance::download_data("wrds_crsp_monthly")` interface, which wraps the WRDS PostgreSQL API. Configure WRDS credentials once with `tidyfinance::set_wrds_credentials()`. Approximate cost: institutional WRDS subscriptions vary; individual researchers cannot subscribe. The raw extracts are not redistributed.

#### Compustat Fundamentals Annual (proprietary)

S&P Global Compustat Fundamentals Annual provides accounting data including total assets used to construct the asset-growth signal. Access requires WRDS, as above. Data are downloaded via `tidyfinance::download_data("wrds_compustat_annual")`. The raw extracts are not redistributed.

#### Ken French Data Library (public)

Monthly Fama-French three-factor returns are downloaded via `tidyfinance::download_data("factors_ff_3_monthly")` from `https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html`. The data are freely available subject to the citation requirement on the source page.

#### `tidyfinance` factor library (public, authors' artefact)

A precomputed library of long-short portfolio returns across `r format(nrow(tidyfinance::download_data("tidyfinance", "factor_library_grid")), big.mark = ",")` construction specifications is hosted on Hugging Face under `tidy-finance/factor_library`. Replicators access the library via `tidyfinance::download_data("tidyfinance", "factor_library", sorting_variable = "ag")`. License: CC-BY-4.0.

## Computational Requirements

### Software Requirements

- R 4.5.2 (versions of every package are pinned in `renv.lock`)
- `renv` package, used to restore the locked package environment
- Quarto (tested with version 1.5 or later) and a working TeX distribution (e.g., TinyTeX or TeX Live) for PDF rendering
- `tidyfinance` (latest CRAN release at the time of compilation, pinned in `renv.lock`)
- An institutional WRDS account, unless rendering with `data_domain <- "pseudo"`

The file `renv.lock` lists every package and version used. Running `renv::restore()` once from the project root installs the full environment.

## Description of programs/code

- `jss-manuscript.qmd` is the Quarto source for the paper. It pulls precomputed factor returns from Hugging Face and CRSP/Compustat extracts from WRDS, and it produces every table and figure in the manuscript.
- `bibliography.bib` contains the BibTeX references.
- `code/01_define_portfolio_sorts_grid.R` defines the grid of portfolio-sort specifications (breakpoints, weighting schemes, lag conventions, sample filters) used by the precomputed factor library.
- `code/02_download_raw_data.R` downloads CRSP and Compustat raw data from WRDS and stores them as parquet files in `data/raw/`.
- `code/03_sorting_variables_monthly.R`, `code/03_sorting_variables_quarterly.R`, `code/03_sorting_variables_yearly.R` construct sorting variables at monthly, quarterly, and annual frequency.
- `code/04_sorting_variables_combination_lag.R` applies the lagging conventions defined in the grid.
- `code/05_portfolio_sorts.R` runs portfolio sorts across every specification in the grid.
- `code/06_analyze_diagnostics.R` computes diagnostics and Sharpe ratios for the precomputed library.
- `renv.lock` pins every R package version.

## Instructions to Replicators

### Path 1: Render the manuscript (default, recommended)

1. Clone the repository and open the project root in R or in your shell.
2. Install `renv` and restore the locked environment:

   ```r
   install.packages("renv")
   renv::restore()
   ```

3. Configure WRDS credentials once (skip if you will use the synthetic-data path):

   ```r
   library(tidyfinance)
   set_wrds_credentials()
   ```

4. Render the PDF from the project root:

   ```bash
   quarto render jss-manuscript.qmd
   ```

### Path 2: Render without WRDS (synthetic data)

Open `jss-manuscript.qmd`, find the `set-data-domain` chunk at the top of Section 4, and change

```r
data_domain <- "wrds"
```

to

```r
data_domain <- "pseudo"
```

Every chunk that would otherwise download CRSP or Compustat then dispatches to the `domain = "pseudo"` path in `tidyfinance`, which generates schema-compatible synthetic data. The workflow reproduces; numerical results are simulated. The `seed` and `n_assets` arguments to `download_data()` control the synthetic draws.

### Path 3: Regenerate the precomputed factor library (audit path, optional)

Reviewers who want to regenerate the published factor library from raw WRDS data instead of consuming the precomputed Hugging Face artefact can run the construction pipeline directly. This path takes about 3 hours on a 64-core machine and is **not required** to reproduce the manuscript:

```bash
Rscript code/01_define_portfolio_sorts_grid.R
Rscript code/02_download_raw_data.R
Rscript code/03_sorting_variables_monthly.R
Rscript code/03_sorting_variables_quarterly.R
Rscript code/03_sorting_variables_yearly.R
Rscript code/04_sorting_variables_combination_lag.R
Rscript code/05_portfolio_sorts.R
Rscript code/06_analyze_diagnostics.R
```
